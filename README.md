# Order Management API

**Описание:**  
REST API для управления заказами интернет-магазина с поддержкой создания и получения заказов, включая данные о доставке, оплате и товарах.

**Бизнес-ценность / Применение:**  
Демонстрация навыков разработки backend-приложений на Rust с использованием современных веб-фреймворков и баз данных. Проект может служить основой для e-commerce платформ или систем управления заказами.

**Ключевые функции:**

- [ ] Создание новых заказов с полной информацией (доставка, оплата, товары)
- [ ] Получение списка всех заказов с детализированными данными
- [ ] Транзакционная обработка данных с поддержкой отката операций
- [ ] Валидация и сериализация JSON-данных
- [ ] Подключение к PostgreSQL с пулом соединений

**Технологии:**

- Языки: Rust
- Библиотеки/фреймворки: Axum, SQLx, Serde, Tokio, PostgreSQL

**Демо-сценарии:**

- Создание заказа через POST запрос с данными о доставке, оплате и товарах
- Получение всех заказов через GET запрос с полной информацией
